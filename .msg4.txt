feat: 用户名注册 + 后台在线设置 + 用户管理增强 + 更新记录（v1.0.0）

1. 注册改用「用户名 + 口令」，不再要求邮箱
   - 登录标识统一叫用户名（3~32 字符，支持中英文与 _ - . @，不含空格）
   - 邮箱格式的标识仍合法 —— 老用户（历史上用邮箱注册）照常登录
   - 显示名变成可选，不填就用用户名
   - 同步：注册页、登录页（「邮箱或登录名」）、邀请码页文案、后台建号

2. 后台文案收敛
   - 状态从「已审批 / 待审批」改为「正常 / 待确认 / 已封禁」（用户只关心正不正常）
   - 邀请码页更正过期说明：注册即用，不再走审批

3. 后台设置：在线修改 + 持久化 + 立即生效
   - 新增 app_settings 表（迁移 0003）与 SettingsService
   - 环境变量只提供**初始值**，之后以数据库为准 —— 重启不会把运维改的值冲掉
   - 可改：允许自助注册、注册需要邀请码、每用户账号数、全局并发上限、
     日志保留天数、登录态有效期
   - AuthService（注册开关/邀请码/额度/会话时长）与 RunnerRegistry（并发上限）
     都改成读运行时设置；界面上标出「已改动」并可一键恢复初始值
   - 坏 JSON / 已下线的设置项只退回默认值，不影响启动

4. 用户管理增强
   - 搜索（用户名或显示名）、状态与角色筛选（药丸式，带数量）、分页
   - 勾选后批量：封禁 / 解封 / 设为管理员 / 降为普通用户
   - 批量逐条执行并回报失败原因（保住「不能封自己」「不能封最后一个管理员」约束）
   - 每人显示：游戏账号数/上限、注册时间、最近登录时间
   - 单人重置口令（重置后该用户所有登录态立即失效）

5. 更新记录（v1.0.0 起）
   - 新增 server/src/version.ts：版本号 + 面向用户的变更日志（只写用户能感知的变化）
   - 公开接口 /api/auth/changelog（登录前也能看）
   - 用户端与后台都加了「更新记录」页；登录页底部显示当前版本
