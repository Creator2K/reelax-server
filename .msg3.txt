fix: 管理员登录名被前端拦下 + 资源卡大数换行 + 去掉内部标识与游戏地址

1. 管理员用 admin 登录报「邮箱格式不正确」（真 bug）
   登录表单字段写死了 .email() 校验，而内置管理员登录名是 admin，不是邮箱。
   后端本来是按同一字段匹配（findByEmail），前端这道限制纯属多余。
   改为「邮箱或登录名」的纯文本输入。

2. 资源卡大数换行
   金币 1642.7 万 这类值在窄卡里会挤到第二行，三张卡高度不齐。
   新增 fmtCompact()：压到 ≤3 位有效数字 + 单位且不留空格（1643万 / 12.3亿 / 5153），
   精确值放 title（悬停可看）。fmtNum 不变（别处仍需带空格的常规格式）。
   StatCard 数值容器加 overflow-hidden + break-all，作为超长数字的兜底。

3. 模块卡片不再显示内部标识
   去掉 keep-online / daily-checkin 这种 module id。

4. 去掉「游戏地址」
   - 添加账号的高级设置里删除该输入框（固定用服务端配置，默认 https://reelax.cn）
   - 账号详情、后台系统页、后台仪表盘都不再显示它

测试：366 项全绿；typecheck / lint / build 通过
