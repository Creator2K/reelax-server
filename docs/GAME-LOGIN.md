# 游戏一键登录

账号管理页的每个账号卡片都提供「打开游戏」。

## 扩展方案（推荐）

1. 在账号管理页点击「游戏登录扩展」。
2. 下载扩展 ZIP 并解压。
3. 打开 `chrome://extensions` 或 `edge://extensions`。
4. 开启开发者模式，选择「加载已解压的扩展」。
5. 回到管理页刷新一次。

之后点击账号卡片的「打开游戏」，扩展会使用一次性票据取得该账号的游戏会话，写入 `reelax.cn` 的登录 Cookie，并打开游戏新标签页。

扩展下载包由当前面板动态生成，权限只包含当前管理端域名和 `reelax.cn`。

## 书签方案（无扩展）

1. 在「游戏登录扩展」弹窗中，把「Reelax 自动填写」拖到书签栏。
2. 点击账号卡片的「打开游戏」。
3. 游戏页面打开后，点击书签。
4. 扩展脚本会读取一次性票据，自动填写邮箱和密码，但不会自动提交。

Cookie 导入账号没有可填写的密码，只能使用扩展方案。

## 安全约束

- 启动票据 45 秒过期，只能使用一次。
- 票据按账号和登录方式绑定，浏览器端不能把 Cookie 票据改成密码票据。
- 扩展方案不会把密码返回给管理网页。
- 书签方案只允许游戏源读取兑换响应，并返回一次账号密码用于自动填写。
- 浏览器直连游戏时，出口 IP 是当前浏览器网络，不是服务器给账号配置的代理。
